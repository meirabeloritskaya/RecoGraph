#  RecoGraph - Система рекомендаций подарков

RecoGraph — это веб-приложение на Django с REST API, использующее PostgreSQL для хранения данных, Redis для кэширования и Celery для обработки фоновых задач.

##  Описание

Проект предназначен для подбора подарков на основе предпочтений пользователей с использованием алгоритмов машинного обучения.  
Приложение включает:
- **Рекомендации товаров** (PageRank, k-NN, коллаборативная фильтрация).
- **Аналитику и статистику пользователей** (популярные товары, действия пользователей).
- **Кэширование в Redis** для ускорения API.
- **Celery** для фоновой обработки задач (например, обновление рекомендаций).

##  Требования

- Python 3.12
- PostgreSQL (для хранения данных)
- Redis (для кэширования результатов)
- Poetry (для управления зависимостями)
